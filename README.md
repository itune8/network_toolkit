# NetProbe

Network Analysis & Monitoring Toolkit — a comprehensive suite of networking tools with an interactive web UI.

## Features

- **DNS Lookup & Analysis** — Resolve any DNS record type, full domain reports, reverse lookups
- **Port Scanner** — Multi-threaded TCP port scanner with service detection
- **HTTP Endpoint Monitor** — Health checks with SSL certificate validation
- **Subnet Calculator** — CIDR calculator, IP analysis, subnet membership checks
- **Traceroute & Ping** — Network path tracing with hop-by-hop latency

## Tech Stack

- Python, Streamlit, Plotly, dnspython, Requests

## Quick Start

```bash
pip install -r requirements.txt
streamlit run app.py
```
